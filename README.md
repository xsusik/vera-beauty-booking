# Vera Beauty Room — сайт записи

Отдельный проект для Vercel. Цены перенесены с фотографии. Заявка сохраняется в Upstash Redis и отправляется маме в Telegram. Она подтверждает визит клиентке лично.

## Подготовка

В config.json сейчас bookingEnabled: false. Это демонстрационный режим с выбором услуг и примерными часами, без отправки заявки.

График выбран как пример — декабрь 2026, понедельник–пятница, 09:00–18:00, перерыв 13:00–14:00. 24, 25 и 31 декабря закрыты. Все длительности услуг и дополнений предварительные. Перед запуском согласуйте их с мамой.

French / babyboomer считается дополнением к покрытию. Рисунки считаются по количеству ногтей, снятие после другого мастера добавляется к покрытию. French в разделе педикюра добавляется к педикюру. Проверьте эту трактовку прайса с мамой.

## Публикация и Telegram

1. Создайте отдельный репозиторий GitHub и загрузите содержимое vera-booking в его корень, включая api, lib и config.json.
2. Импортируйте в Vercel с Framework Preset Other. Root Directory должна указывать на папку с index.html. Установка npm-пакетов и сборка не нужны.
3. Создайте бота через @BotFather. Мама должна открыть бота и нажать Start.
4. После её сообщения боту получите её chat_id через getUpdates Telegram Bot API. Токен храните в настройках Vercel.
5. Создайте Upstash Redis и задайте Production Environment Variables из списка ниже.
6. Проверьте сведения о салоне, график и информацию об использовании персональных данных. Контакт салона сейчас — Instagram.
7. Для теста включите bookingEnabled на закрытом тестовом деплое, отправьте заявку со своим номером и проверьте Telegram. После проверки можно включить запись на рабочем сайте.

Переменные Vercel:

- UPSTASH_REDIS_REST_URL — REST URL базы.
- UPSTASH_REDIS_REST_TOKEN — REST token базы.
- TELEGRAM_BOT_TOKEN — секрет из BotFather.
- TELEGRAM_CHAT_ID — чат мамы с ботом.
- CRON_SECRET — случайный секрет минимум 32 символа для задания повторной отправки.

После задания переменных сделайте Redeploy. Секреты должны храниться вне GitHub. На GitHub Pages работает только демонстрационный интерфейс, реальная отправка требует серверных функций Vercel.

## Как менять график

В config.json поля schedule.from и schedule.to задают диапазон дат. weekdays — дни недели от 0 до 6, где 0 — воскресенье. start и end — часы работы. breaks — перерывы, closedDates — полностью закрытые даты.

В blocked можно закрывать часы, занятые вручную, например: "2026-12-03": [["10:00", "12:00"]]. Все часы в польском времени Europe/Warsaw. duration — продолжительность услуги в минутах. Используйте положительные длительности, кратные пяти минутам.

## Хранение и отмена

- vera:booking:records — заявки по ID.
- vera:booking:day:YYYY-MM-DD — занятые пятиминутные отрезки с ID заявки.
- vera:booking:outbox — очередь уведомлений, ожидающих отправки.

Сервер атомарно проверяет и занимает время. Цены считает по серверному прайсу. Повтор той же заявки с тем же ID возвращает её результат.

При ошибке Telegram заявка сохраняется и блокирует время. Повторная отправка запускается ежедневно в 07:00 UTC. Задание можно запустить вручную в Vercel Cron Jobs. Если соединение оборвалось после фактической доставки сообщения, возможно повторное уведомление с тем же ID заявки.

Для отмены в панели Redis удалите пятиминутные поля заявки из соответствующего дня и затем записи этого ID из records и outbox. Перед удалением проверьте принадлежность полей нужной заявке. ID есть в сообщении Telegram.

## Как подключить заявки в CRM

1. Обновите проект CRM на Vercel. В его настройках задайте те же `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`, что и в проекте сайта записи. Добавьте `BOOKING_INBOX_KEY` — отдельный длинный пароль (минимум 24 символа). В GitHub загружайте только примеры переменных без их значений.
2. В проекте сайта записи добавьте `CRM_URL` с публичным адресом CRM через HTTPS. Это добавит в Telegram ссылку, ведущую в раздел заявок. Разверните оба проекта после сохранения переменных.
3. Мама открывает **Zapisy online** в CRM и один раз вводит пароль. Сессия действует 30 дней в том же браузере. Через **Wyloguj ze skrzynki** можно выйти.
4. **Potwierdź i dodaj** подтверждает заявку и сохраняет визит в календарь на этом устройстве. **Odrzuć** освобождает время на сайте. Для связи с клиенткой нажмите её телефон на карточке. Если запись в календарь не удалась, подтверждённая заявка останется доступна для повторного добавления.

График CRM хранится в браузере. Если визит записали вручную, добавьте его время в `schedule.blocked`, чтобы сайт его не предложил. При импорте CRM проверяет пересечения с визитами на текущем устройстве. Правки и отмены уже импортированных визитов в CRM не меняют график на публичном сайте.

Данные заявки хранятся до удаления владельцем. Перед запуском определите порядок хранения и удаления заявок. Реальная доставка в Telegram проверяется после подключения сервисов.

Документация интеграций: [Telegram Bot API](https://core.telegram.org/bots/api#sendmessage), [Upstash REST API](https://upstash.com/docs/redis/features/restapi), [Vercel Cron](https://vercel.com/docs/cron-jobs).
